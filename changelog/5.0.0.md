## Update 5.0.0

## New
- Переписана вся графическая часть мода для оптимизации процесса адаптации под новые версии Майнкрафта.
- **ВНИМАНИЕ!** Была полностью переписана система хранения настроек и пресетов. При переходе на эту версию мод автоматически сделает бекап ваших старых настроек и конвертирует их под новый формат.
- Теперь бинды можно экспортировать, получая в буфер обмена строчку вида `fastbind://<code>`. Эту строчку вы можете отправить своему другу, а он посредством кнопки Import может вставить её в текущий слот.
- Каждому пресету можно изменить количество строчек и рядов на страницах. Изменение размеров с большого на маленький НЕ удаляет заранее указанные там бинды.
- Добавлена система `Переменных`. В специальном окне редактора вы можете узнать о встроенных переменных, или добавлять свои.
- Переменные можно использовать в экшенах: `Command`, `Message in chat`, `Screen title`, `Toast`
- Новые экшены:
- - **Toast** – выводит фейковое уведомление в стиле достижений. Можно выбрать вид достижения и указать свою подпись.
- - **Play sound** - воспроизводит выбранный звук из игры (поддерживает звуки из модов), или же из папки. Поддерживаются звуки в формате `.ogg`, их необходимо добавить в папку `<your_minecraft_instance>\nitsha\fastbind\sounds`. Если вам необходимо проигрывать разные звуки в один момент, вы можете назначить каждый звук на свой слот. Всего имеется 9 слотов.
- - **Change variable** - позволяет изменить значение добавленных вами переменных. Для удобства есть два режима изменения: local и global. Global режим изменит значение переменной для всех экшенов, где она используется. Local изменения будут доступны в рамках выполнения исполняемого экшена. Изменять встроенные нельзя.
- Окно редактора экшенов теперь можно растянуть на всю ширину экрана.
- В выборе Key event добавлен поиск
